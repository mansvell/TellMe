# Notes de test pour les stores — brouillon

À compléter après les fonctions de publication et le déploiement de la version finale. Le fonctionnement anonyme décrit ici doit rester explicitement indiqué à l'équipe de validation.

- L'app crée une identité sous pseudo lors de la première inscription, avec acceptation des conditions. Elle ne possède pas de formulaire classique de reconnexion. La session est conservée sur l'appareil.
- Accueil : créer un groupe, choisir son nom et sa durée, puis partager son lien. Un deuxième appareil ou une session indépendante permet de rejoindre le groupe et de tester les échanges.
- Buzz : créer un sondage ou sélectionner une question, publier dans un groupe et essayer le vote.
- Fun : consulter ou publier une Storytime textuelle anonyme. Les histoires sont visibles 24 heures aux membres inscrits. L'auteur retrouve ses histoires et leurs vues dans Mes Storytimes.
- Secrets : partager le lien personnel. L'ouvrir dans une session sans compte, envoyer un message, puis consulter le message dans Fun sur l'appareil destinataire. La réponse se prépare sous forme de carte partageable ; aucune conversation privée ne s'ouvre automatiquement avec l'expéditeur externe.
- Paramètres : langue FR/EN/DE, thème et préférences. Le support ouvre le contact e-mail affiché.
- Notifications natives : pas encore configurées, ne pas les présenter comme opérationnelles dans les notes soumises.
- Avant l'envoi, ajouter les étapes concrètes de suppression du compte, de blocage et de signalement/modération une fois ces fonctions implémentées et testées.
- Fournir des liens de test actifs sur le domaine public et toute instruction d'accès nécessaire. Aucun identifiant de test ni mot de passe n'a été créé dans cette préparation.
